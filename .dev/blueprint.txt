## 8. SESSION SECURITY / AUTO LOGOUT

Implement an activity-based session timeout.

### Rules
- SESSION TIMEOUT: 30 MINUTES OF INACTIVITY.
- This is an IDLE/INACTIVITY timeout, NOT a fixed session duration.
- Any genuine user activity resets the inactivity timer.
- Activity includes interaction with the system such as clicking, typing, navigation, or other active interaction.
- If the user remains active, the session must remain open indefinitely, even for multiple days.
- After 30 continuous minutes with no activity, automatically log the user out.
- Return the user to the LOGIN page after automatic logout.
- NO WARNING or countdown notification before logout.
- Simply leaving the system open is NOT considered activity.
- Do not change the existing authentication behavior beyond this inactivity timeout.
